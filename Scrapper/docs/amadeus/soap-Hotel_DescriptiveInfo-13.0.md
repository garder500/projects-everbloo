# Function: Hotel\_DescriptiveInfo

* * *

## 1 Overview

### Hotel Textual and Multimedia Content

-   **Query:** OTA\_HotelDescriptiveInfoRQ
-   **Response:** OTA\_HotelDescriptiveInfoRS

The message is used to retrieve the hotel textual and multimedia descriptive content. An End-user application sends the **query** to the Amadeus Hotel distribution platform requesting the Hotel descriptive content information **response**.

The Hotel Descriptive Content contains descriptions about the hotel property. It provides users with a wide range of direct or indirect information concerning the hotel, as well as other information that may be of interest to the guest. Some features are "searchable" and can be used as search options using the Amadeus “Hotel List” or ”Hotel Multi” functionalities.

The Hotel Descriptive Content is a structured content message compliant with the **OTA 2011A** travel industry standard. Furthermore, the character encoding is **UTF-8** which ensures multilingual content support.

The user is able to request a specific language. If not requested or available, either the property default language, or the system default (**en**) is returned.

Language coding follows the **ISO 639-1** standard.

## 1.1 Supported Operations

Each content operation is a particular case of the content retrieve query. It is determined by the echoToken element which will take different values.

1) (Standard) Single property content Retrieve

• **Mandatory EchoToken="WithParsing"**

• Requested for single property content information.

• Only the requested language (@PrimaryLangID) is returned.

• If the requested language is not available, the default language is returned.

• If none of the language is requested, then either English by default or the first availablelanguage is returned.

• All categories can be returned.

• All types of content can be returned ( textual, multimedia).

2) (Owner) Single property content Retrieve

• **Mandatory EchoToken="Owner"**

• All available languages are returned.

• Requested for single property content information.

• All categories can be returned.

• All types of content can be returned ( textual, multimedia).

Note: EchoToken =”Normal” behaves in same way as EchoToken “Owner”, except that it will not retrieve Cryptic texts.

3) Multiple property content retrieve or Partial Content Retrieve

-   **Mandatory EchoToken="PartialWithParsing"**

• Used for a multiple property retrieve; all requested properties are returned within the same response message.

• It is ideally used in conjunction with multiple property availability or any other hotel listing.

• Only a subset of amenities can be returned

• Only one image is returned.

4)  Configuration Retrieve

-   **Mandatory EchoToken="WithConfig"**

• In all the above cases, only the Descriptive Content for a hotel is retrieved.

• There are some parts of the information for hotel which don’t relate to Content (eg: hotel address) and these are stored as “configuration”.

• These config information can be retrieved along with descriptive contents by defining the EchoToken as “WithConfig”.

Remark: Each operation either extends or limits the categories which can be requested in "Bulding A Query" section.

## 1.2 Limitations

-   Multiple Property Content Retrieve
    
    -   Only retrieves a pre-defined set of amenities.
    -   Only retrieves a single image.
    
    See the operation description for more details.

## 1.3 Unsupported Operations

Not applicable

## 1.4 Prerequisites

The user needs to know the list of Amadeus properties beforehand. The content will only be returned for the requested properties.

The property code:

-   is the **key** premise.
-   has to **exist** in Amadeus systems.
-   has to abide to the **same format**.
-   needs to be an **exact match**.

## 2 Building A Query

The following categories can be requested separately:

-   Request a primary language (OTA\_HotelDescriptiveInfoRQ@PrimaryLangID)
-   Request content for one or more properties
    -   By requesting either one or many HotelDescriptiveInfo elements.

-   Request to have one or more of the content following categories (boolean attributes which are either set to true or false)
    -   Hotel General information (HotelInfo@SendData="true")
        -   Hotel rating is contained within HotelInfo element.
    -   Hotel Meeting rooms (FacilityInfo@SendMeetingRooms)
    -   Hotel Guest rooms (@SendGuestRooms)
    -   Hotel Restaurants (@SendRestaurants)
    -   Hotel Policies(Policies@SendPolicies)
    -   Hotel Reference points(AreaInfo@SendRefPoints)
    -   Hotel Attractions (@SendAttractions)
    -   Hotel Recreations (@SendRecreations)
    -   Hotel Loyalty programs (AffiliationInfo@SendLoyalPrograms)
    -   Hotel Awards (@SendAwards)
    -   Hotel Contact information (ContactInfo@SendData)

-   Request Hotel Multimedia information
    -   Multimedia objects are returned within the relevant element (see content categories above)
    -   Boolean attribute is MultimediaObjects@SendData

-   Request secured URLs (Https:)
    -   Attribute is ContentInfos/ContentInfo@Name="SecureMultimediaURLs"
-   Request Reviews
    -    Attribute is TPA\_Extensions/Reviews/Review@ReviewerCompany

Remarks:

-   Refer to complete Request mapping for details.
-   When none of the above attributes is requested, by default all categories are returned with non secured multimedia URLs.
-   Limitations apply on the multiple property retrieve. Please refere to the limitations section of the message.

2.1 Rules for retrieving the requested information

\- The Boolean Flag is False, the information addressed by the Boolean flag is not returned

\- The Boolean Flag is True, the information addressed by the Boolean flag is returned (if any).

\- None of the Boolean Flag are set, the unset Boolean flag are considered as true and the information they address is returned (if any).for the property.

\- Some of the Boolean Flag are set to False and others are set to True, the unset Boolean flag are considered as False and the information they address is not returned

\- Some of the Boolean Flag are set to False and none are set to true. the unset Boolean flag are considered as True and the information they address is returned (if any).for the property.

\- Some of the Boolean Flag are set to True and none are set to False, the unset Boolean queryflag are considered as False and the information they address is not returned.

## 3 Receiving A Reply

Depending on the operation, the **complete** (content) or only a **subset** (of the entire content) will be returned

Please refer to each **operation** described below.

On one hand, the standard retrieve operation describes the full message mapping.  On the other hand, multiple and single property retrieve operations are defined by how they differ from the standard retrieve.

The requested **language** is returned. If that requested language is not available, the system returns the default property language defined (HotelDescriptiveContent@LanguageCode) or the system default (English). Note that if a multilingual description exists, it will at least be available in English.

Remark:

-   URLs should not be parsed (when decoding the response content message on client side). URLs are not structured and they might change in the future; the user should use URLs as-is.
-   The user should never store/copy the multimedia file itself. This rule ensures that all subscribers benefit from the latest multimedia updates.

## 5 Operations

## 5.1 Operation: Government Id and Vacation Policy information

### Government Id/License Mandate Information:

To support regulatory compliance and enhance hotel metadata, a new <IdentityDetails> node is introduced under <TPA\_Extensions> in the OTA\_HotelDescriptiveContent schema. This node captures government-issued identification details, such as national ID types required by local authorities.

There is no specific parameter in the request to return Government Id Information, it is always returned by default if the content has the details of Government id. 

IdentityDetail

Identity detail would be an Array in XML to repeat name and description.

Id

Refers the Government Id

Description

Additional description for the Government id

### Vacation Rental Policy Information:

Vacation rentals are fully furnished properties (e.g., houses, villas, chalets) rented short or long-term for leisure. They have certain Check In Date and Check Out time. A new California law requires vacation rental properties to disclose mandatory cleaning tasks for travelers

Two new policyInfocodes are added in the description schema

-   Check Out Instructions
-   Damage Deposit

The PolicyInfoCode are already part of the schema and they would return Vacation rental policy information with the new codes

Example

<PolicyInfoCode>

<Description Name="Check-OutInstructions" >

<Text Language="en">The host requests you complete the following cleaning tasks before checking out</Text> 

</Description>

</PolicyInfoCode>

<PolicyInfoCode Name="DamageDeposit">

<Description>

<Text Language="en">Smoking Penalty: A USD $1,000 fee is charged for smoking inside the property or on balconies</Text>

</Description>

</PolicyInfoCode>

## 5.2 Operation: Loyalty Information retrieve

### Loyalty Information:

This operation is typically used when the Hotel Providers return Loyalty Information.

There is no specific parameter in the request to return Loyalty Information. When the content of the Hotel contains loyalty information, it would be returned in the Response.

It provides the user with basic information about Loyalty details

-   Loyalty Program along with Brand code details.
    
-   **Tier Name**: Tier specifies the name of the tier (e.g., Gold, Silver, Bronze).
    
-   **Eligibility** : Describes the minimum requirement to qualify for the tier.
    
-   **StayToPointsConversion**: Indicates how many points are earned per dollar spent on room stays.
    
-   **RewardPoints**: The number of reward points granted, possibly as a joining bonus or annual benefit.
    
-   **DiscountPercent**: The percentage discount offered to members of that tier.
    
-   **AdditionalPerks**: Lists extra benefits exclusive to the tier.
    
-   Logo URL: Proram containing Logo Image (ImageCategory=15).

## 5.3 Operation: Partial Content Retrieve

This operation is typically used in conjunction with a multiple property availability or any other **hotel listing**.

Each property is requested in a separate **HotelDescriptiveInfo** section.

It provides the user with basic information about one or many hotels in the same message.

-   Mandatory EchoToken="PartialwithParsing" 
    
-   Used for a **multiple** property retrieve; all requested properties are returned within the same response message.
    
-   It is ideally used in conjunction with a multiple property availability or any other **hotel listing**.
    
-   Only a **subset of amenities** can be returned 
    
-   Only **one image** is returned (see the image selection rules below).
    
-   When the tag "SecureMultimediaURLs" is present at least once (in a HotelDescriptiveInfo section), **secured URLs** will be returned for all properties within the message.
    

Available amenities:

-   Children club/activities (HAC @code="193")
-   Restaurant (HAC @code="76")
-   Parking (HAC @code="68")
-   Swimming-pool (HAC @code="66", "54", "49" or "71")
-   Pets Accepted (HAC @code="224")
-   Internet Access (HAC @code="223")
-   Health club (RST @code="36")
-   Beach (RST @code="5")
-   SPA (HAC @code="84")
-   Air Conditioning (RMA @RoomAmenityCode="2")
-   Bar (HAC @code="165")
-   Business Centre (BUS @BusinessServiceCode="39")
-   Meeting Rooms (BUS @BusinessServiceCode="46")
-   Laundry service / Valet (HAC @code="58")
-   Room Service (HAC @code="2" or "77")
-   Safe deposit box (HAC @code="78")
-   Hotel Address including City Name and Postal Code (ContactInfos/ContactInfo@Location="6" - Hotel direct)
-   Languages spoken (e.g. @Language="fr")
-   Number of rooms (GuestRoomInfo@Quantity and @code="28")
-   Disable Access (Feature@AccessibleCode= "6")
-   User rating (Awards/Award)

## 5.4 Operation: Single property full content retrieve

(Online) Travel agents typically request standard hotel descriptive content information. All the available information for a **single** hotel is returned in the requested language.

### (Standard) single property retrieve:

-   The standard retrieve operation is triggered when hotel descriptive content is requested with the **echoToken="withParsing"** mandatory attribute.
-   Only the requested **language** (@PrimaryLangID) is returned. If not available, the default language is returned.
-   When the requested language is not available (or has not been requested), either english by default or the first available language is returned.

### (Owner) single property retrieve:

-   The owner retrieve operation is triggered when hotel descriptive content is requested with the **echoToken="Owner"** mandatory attribute.
-   All available description languages are returned.

**All content categories** and types can be returned depending on the query (please refer to the HotelDescriptiveInfo query above).
