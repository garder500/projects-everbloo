# Function: PAY\_DeleteVirtualCard

* * *

## 1 Overview

A virtual card is a B2B method of payment used by travel agencies to pay their suppliers and ease the reconciliation process. 

PAY\_DeleteVirtualCard contains the following functions:

-   Query: PAY\_DeleteVirtualCardRQ
-   Response: PAY\_DeleteVirtualCardRS

This guide describes how to use this function.

## 1.1 Supported Operations

This function allows the travel agency to delete a virtual card previously created with the PAY\_GenerateVirtualCard using either the external or the Amadeus reference of the card.

## 1.2 Limitations

A virtual card can only be deleted if it has previously been created with the PAY\_GenerateVirtualCard.

Only one virtual card can be deleted per message.

## 1.3 Unsupported Operations

Not applicable

## 1.4 Prerequisites

-   LSS right (MANAGE\_VCN) to be given per currency
-   To be in the generation office (one can only delete a card if one is in the same office that generated it)
