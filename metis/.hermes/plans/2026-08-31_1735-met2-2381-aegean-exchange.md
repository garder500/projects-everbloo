## 🚨 Gaps critiques identifiés (à traiter)

1. **Reshop partiel perdu** : le front calcule `RetainServiceID` (`AegeanAdapter:599-605`) mais le backend
   `jsonQuery` l'**ignore** → `Delete` de TOUS les `P-*` + `Add` des seuls segments cochés ⇒ l'OD non modifié
   risque d'être supprimé sans être ré-ajouté. **Bug majeur** pour « modifier un seul OD ».
2. **Capabilities A3 = défauts** (`booked.allSegments=false` ⇒ 1 OD, `ticketed.allSegments=true` ⇒ tout).
   Pas de capability `changeDate` (le date-picker n'est gâté par rien, seul l'**aéroport** l'est via `changeLocation`).
3. **`getReshopOffer` A3 orphelin** — code mort à brancher (edit/index.vue branche A3/OA) ou retirer.
4. **Devises (§12)** : scaling incohérent `÷currencyFactor` (path A) vs `÷100` codé en dur (path B)
   ⇒ faux pour JPY(0)/KWD/TND(3). Devise de réponse ≠ devise PDV (pas de conversion agence).
5. **EMD-S absent** pour pénalité/différentiel (seulement `createEmdA`).
6. **Garde-fou** offre expirée / IDs régénérés : `selectionMismatch` gâté `[IB,BA]` seulement ⇒ A3 non protégé.
7. **Escale** : `jsonQuery.Add` ne modèle qu'**un** `Departure`/`Arrival` par OD ⇒ un OD à connexion (2 vols)
   non modélisable tel quel.
8. **Multi-pax** : prix agrégé, pas de désagrégation explicite par pax dans le RQ.
